# Sarv Samaj Kalyan Samiti — Modular React Frontend

The website is now organized into separate React component folders. Each component has a matching CSS file; shared design tokens live in `src/styles/variables.css`, and shared reset/layout/responsive rules live in `src/global.css`. Theme uses saffron/orange, cream/white and dark text.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Notes
Phone, email, donation flow, campaign figures, events, and activity content include illustrative placeholders and should be verified before publishing. Donation buttons are not connected to a payment processor.
